业务场景    
主体检测在电商场景里远不止“图搜前的预处理”，以下是一些常见且有价值的使用方向，可以帮你拓宽项目的应用场景表述：
1.商品审核与合规性检查
违禁品过滤：自动检测上传的商品图中是否包含枪支、管制刀具、野生动物制品等违禁物品。
敏感内容屏蔽：识别色情、暴力、政治敏感等不符合平台规定的图片。
品牌侵权检测：检测商品图中的Logo、图案是否涉及仿冒知名品牌。

2.商品主图优化与标准化
自动抠图与背景替换：精准提取商品主体，去除杂乱的拍摄背景，统一替换为纯色或标准模板背景，提升商详页美观度。
智能裁剪与构图：根据主体位置自动裁剪图片，确保商品居中、大小合适，符合不同展示位（如首页推荐、搜索结果列表）的尺寸要求。

3.以图搜图与相似商品推荐
视觉搜索：用户上传一张实物照片，系统通过主体检测定位核心商品，再与数据库中的商品特征进行比对，找到最相似的售卖链接。
搭配推荐：检测出图中某件商品（如一件连衣裙），进一步分析其颜色、款式，推荐与之搭配的鞋包、配饰

### 1. 商品主图质量审核
- 检测商品是否居中、是否占画面足够比例
- 判断是否有多余物体、人物手部、水印遮挡主体
- 平台规范校验（如淘宝/亚马逊要求主体清晰、背景干净）

### 2. 自动裁剪与缩略图生成
- 根据检测框自动裁出商品主体，生成 1:1、3:4 等规格的商品主图
- 批量生成列表页缩略图、详情图、活动 banner 素材
- 避免人工裁剪，统一视觉规范

### 3. 背景移除 / 替换
- 先检测主体，再做抠图或背景替换（白底图、透明底、场景化背景）
- 常用于商品上架图标准化、跨境平台图片合规

### 4. 商品内容合规与风控
- 检测图片中是否出现违禁品、敏感物品
- 判断商品图是否包含非卖品、赠品误导、夸大宣传元素
- 与 OCR、分类模型结合做图文一致性审核

### 5. 商品属性自动提取
- 检测主体后，进一步识别颜色、款式、材质、品牌 logo
- 辅助自动生成商品标题、卖点文案、标签
- 为大模型 / Agent 提供结构化视觉输入

### 6. 图文一致性校验
- 对比标题/描述与图片中实际检测到的商品是否匹配
- 防止“挂羊头卖狗肉”、类目错放

### 7. 重复铺货 / 盗图识别
- 检测主体区域后提取视觉特征，判断不同店铺是否使用相同商品图
- 辅助平台治理重复铺货、图片侵权

### 8. 视频 / 直播电商中的商品定位
- 在短视频或直播画面中实时检测商品出现位置
- 用于自动弹窗链接、精彩片段剪辑、直播商品识别

### 9. 智能拍摄辅助
- 拍照时实时提示用户商品是否入镜、是否居中、光线是否合适
- 提升商家上传图片的一次通过率

### 10. 货架 / 陈列识别
- 识别线下货架上的商品陈列情况
- 用于陈列合规检查、缺货检测、竞品分析

### 11. 尺码 / 比例参考
- 检测商品的同时检测参照物（如硬币、手掌），估算商品实际大小
- 减少因尺寸描述不清导致的退货

## 项目概述

开发基于YOLOE的电商商品主体检测服务,通过文本提示词调优、多维综合打分和父子框识别等技术,实现商品主图智能裁剪、质量审核等应用场景。将检测能力封装为标准化API接口,可作为多模态Agent的视觉感知工具,支持Prompt-Free和Prompt-Based双模式检测,为上层业务提供精准的主体定位输入。

## 工作内容

**1. 文本提示词工程与模型调优**  
设计并优化YOLOE的文本提示词列表,通过多轮实验调整类别描述、负面过滤和提示词组合策略,提升玩具类商品检测召回率。探索提示词设计与LLM Prompt工程的相通性,积累任务描述、类别约束等调优经验。

**2. 多维综合打分算法设计与实现**  
设计置信度、面积占比、中心度三维打分机制,实现Z-score、min-max、Rank三种归一化方案,支持动态切换。通过加权融合算法提升主体排序准确性,解决单一置信度排序在复杂场景下的不足。

**3. 父子框识别与结果后处理**  
实现基于覆盖率和IOU的父子框检测算法,对局部配件框(子框)进行得分惩罚,避免次要物体干扰主要主体判断。设计可配置的惩罚系数和阈值参数,支持不同业务场景灵活调整。

**4. 检测服务API化与工具化封装**  
基于FastAPI设计RESTful接口,将主体检测能力封装为可复用的API服务,支持批量检测、多模型切换、参数动态配置。设计标准化的输入输出schema,便于集成到Agent系统作为视觉理解工具。

**5. 动态批处理与性能优化**  
实现动态批处理机制,通过合并并发请求、CUDA Stream并行、CPU多线程预处理等技术,提升GPU利用率和吞吐量。支持运行时配置热更新,无需重启即可调整批处理参数。
