项目二名称：基于 YOLOE 的商品主体检测服务
项目概述：开发基于 YOLOE 的商品主体检测服务，通过 Prompt 调优、多维综合打分和父子框识别算法，解决多主体场景下的精准定位问题。
工作内容：
1、基于 Open-Vocabulary Detection 框架，设计分层 Prompt 体系，建立完善的 Prompt Engineering 优化流程。通过对比实验验证不同类别描述方式以及负面过滤策略对检测召回率的影响，从单一类别扩展到多层级体系，形成"任务描述—类别约束—负面过滤—效果验证"的完整调优方法论；该经验与 LLM 提示词设计在任务建模与约束控制上思路相通，具备跨模态迁移能力；
2、针对复杂场景下的主体排序问题，设计多维度排序机制解决单一置信度排序不足的问题。采用 min-max 归一化有效处理多维度数据的尺度差异，支持置信度、面积、中心度三维度权重可配置，适配不同业务场景；
3、针对主体与配件混淆问题，设计基于覆盖率与 IOU 的双层判定算法：先以覆盖率（>0.9）作为主判定条件锁定典型配件框，再以 IOU（>0.3）与面积比（<0.4）作为补充条件兜底边缘情况，配合自适应惩罚机制（权重×0.1）降低配件框对主体排序的干扰。
3、针对主体与配件混淆问题,设计基于覆盖率的双层判定算法,通过差异化惩罚实现准确率/召回率权衡。强条件(覆盖率>0.9)锁定完全嵌套配件保证准确率,弱条件(0.7<覆盖率≤0.9且面积比<0.3)兜底部分嵌套配件提升召回率,配合自适应惩罚机制施加差异化权重,避免次要物体干扰主要主体判断。
